    Class: PhysicalFeature

    An identifiable place or environmental feature where a property may be observed or measured, or which organizes smaller physical features. A plot, point, stream reach, tower, or modeled location can be a physical feature. A sample, sensor, or organism at a place has its own identity.

    Comments

    • Coordinates are recommended but optional. Supply either latitude and longitude in WGS84 or alternate x and y with their reference system and unit, but not both sets. For a point they locate the feature; for a curve or surface they give a representative position. A feature may have no coordinates.
    • Physical features can be linked into hierarchical relationships using parent_feature to reference a higher-level physical feature.
    • Data source location IDs may be scoped differently. Ingest constructs a URI or CURIE for id, retains the source value in source_location_id, and resolves parent_location_id to the parent's BRIDGE identifier.
    • If data source physical feature does not have name, it is recommended to reuse the source_location_id.
    • LinkML checks that vertical_position_bottom and vertical_position_top are supplied together and are not combined with vertical_position, but does not enforce their numeric order.
    • The ESS-DIVE Location Reporting Format linked in see_also is a pre-release version.
    • BASIN-3D's related feature classes and fields are currently defined in Python, not as published LinkML elements with term URIs. The upstream repository is a conceptual reference for this class and has close_mappings to the Feature > SamplingFeature > SpatialSamplingFeature MonitoringFeature class with feature_type and feature_shape attributes.
