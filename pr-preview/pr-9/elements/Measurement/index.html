    Class: Measurement

    One value of one property of one thing, as reported by a source. A measurement may carry a number with a unit, a range, a summary statistic, a categorical term, or only the source text, and it may say why no value is present. The 2026-09-30 hackathon chose to start with this single class and add an Observation class only when data shows a need for one.

    Comments

    • A record must carry at least one of raw_value, numeric_value, minimum_numeric_value, maximum_numeric_value, value_term or missing_value_reason, so an empty measurement fails validation.
    • A record names its property with exactly one of observed_property (an identifier) or property_label (free text). property_label is the catch-all for values whose property has no identifier yet, as MIxS misc_param, NMDC PropertyAssertion and BERtron Attribute allow.
    • The value slots come in two groups. raw_value, numeric_value, minimum_numeric_value, maximum_numeric_value, unit and value_term hold the value itself: raw_value as the source wrote it, the others as parsed from it (numeric_value for a number, value_term for a category). comparator, statistic, standard_deviation, sample_size, value_role, value_qualifier and missing_value_reason say something about that value.
    • A source cell that holds several values (for example a width and a length) becomes several Measurement records that share source_record_id and source_field.
